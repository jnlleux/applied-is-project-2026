# AutoRent
Учебное АРМ компании по аренде автомобилей. Лабораторные работы 1 и 2.
Четыре сущности: категории, автомобили, клиенты и аренды.

![ER-диаграмма](docs/er-diagram.png)

## Запуск на macOS
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python seed.py
python verify.py
uvicorn app.main:app --reload
```
Проверка сервера: http://127.0.0.1:8000/ . Отдельный каркас UI:
`streamlit run frontend/app.py`.

## Назначение файлов
- app/database/models.py — ORM-модели, ключи и связи.
- app/database/db.py — движок SQLite, внешние ключи и создание таблиц.
- seed.py — по три демонстрационные записи на таблицу; непустая БД не изменяется.
- verify.py — проверка связей, ограничений и повторного запуска seed.
- app/api/ — место для маршрутов следующих лабораторных.
- app/main.py — минимальный FastAPI сервер.
- frontend/app.py — каркас Streamlit.

Все клиенты и номера документов в seed — вымышленные учебные значения.
Деньги хранятся целыми числами в тенге. Тариф копируется в аренду;
изменение категории не меняет историю. Пересечения аренд и авторизация
относятся к следующему этапу и здесь ещё не реализованы.

## VS Code и GitHub
Откройте эту папку в VS Code и выберите интерпретатор `.venv/bin/python`.
В Source Control используйте Publish to GitHub, войдите в свой аккаунт,
выберите имя applied-is-project-2026. Перед публикацией проверьте список файлов:
в нём не должно быть .venv, database.db, .env и секретов.
При наличии репозитория задайте origin его фактическим URL и выполните push.
