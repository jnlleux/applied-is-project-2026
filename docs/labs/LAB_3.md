## Подготовка

Из корня проекта, Python 3.12 или новее:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-lock.txt
python seed.py
python -m uvicorn app.main:app --reload
```

Откройте http://127.0.0.1:8000/docs. Нажмите нужный маршрут, затем **Try it out**, заполните поля и нажмите **Execute**. В разделе **Server response** отображается реальный статус и JSON. Блок **Responses** ниже описывает возможные ответы, а не результат выполненного запроса.

Повторный seed не перезаписывает непустую базу. ID записей берите из текущего GET-ответа: они могут отличаться от примеров.

## Цель и реализация

Создан REST API на FastAPI. При старте lifespan вызывает init_db, затем подключается router. Четыре ресурса: /categories, /cars, /clients, /rentals. Каждый поддерживает получение списка, получение по ID и создание записи. get_session открывает отдельную сессию для запроса через Depends и закрывает её после обработки.

Входные схемы отделены от ORM: пользователь не передаёт id, а данные проверяются до сохранения. Успешное создание возвращает 201; неверные значения — 422; отсутствующий объект — 404; дубликат уникального значения — 409.

## Проверка в Swagger

1. GET /cars → Execute. Ожидается **200** и JSON-массив автомобилей. В исходном seed есть Hyundai Accent, Toyota Camry и Kia K5.
2. POST /categories. Вставьте JSON ниже. Ожидается **201**. Скопируйте выданный id.

```json
{"name":"Лабораторная 3","daily_rate":18000}
```

3. GET /categories/{item_id}. Подставьте полученный id. Ожидается **200** и созданная категория.
4. Повторите POST с тем же названием. Ожидается **409**, поскольку имя категории уникально.
5. Отправьте неправильный тариф:

```json
{"name":"Неверный тариф","daily_rate":-100}
```

Ожидается **422**. В detail отображается поле daily_rate и причина нарушения. GET /categories должен подтвердить, что неправильная запись не появилась.

6. Отправьте пустое название:

```json
{"name":"","daily_rate":18000}
```

Ожидается **422**. GET /categories/999999999 должен вернуть **404**, если такой ID отсутствует.

## Ответы для защиты

**Что такое REST API?** Интерфейс доступа к ресурсам по HTTP. GET читает ресурс, POST создаёт новый. Состояние хранит серверная база, а клиент получает представление в JSON.

**Роль Pydantic?** Проверяет типы и ограничения входных данных. Некорректный запрос отклоняется до записи в базу.

**Зачем Depends?** Управляет временем жизни сессии на каждый запрос. Общая глобальная сессия могла бы смешивать транзакции разных запросов и неправильно освобождать ресурсы.

**Откуда Swagger?** FastAPI формирует OpenAPI по маршрутам и схемам, а Swagger UI отображает его. HTML вручную писать не нужно.

**Что означает 422?** Запрос распознан, но его данные не соответствуют схеме: например, отрицательный тариф или отсутствующее обязательное поле.
