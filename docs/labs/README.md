# Лабораторные работы AutoRent

Достанова Жанелла, ИС/24А. Каждая ссылка открывает отдельный подробный материал с целью, реализацией, проверкой и ответами для защиты.

- [Лабораторная 3 — FastAPI, GET, POST, ошибки 422](LAB_3.md)
- [Лабораторная 4 — PATCH, DELETE, поиск и ошибки 404](LAB_4.md)
- [Лабораторная 5 — формы и таблицы Streamlit](LAB_5.md)
- [Лабораторная 6 — Docker и проверка сохранения данных](LAB_6.md)
- [Лабораторная 7 — автоматические тесты и защита](LAB_7.md)

GitHub хранит исходники и эти материалы. Запросы выполняются в запущенном Swagger на http://127.0.0.1:8000/docs, интерфейс работает на http://localhost:8501. Адреса localhost открываются только на компьютере, где запущен проект.

В VS Code: Terminal → Run Task → выбрать запуск API, интерфейса или тестов.

Статус: API, интерфейс и тесты проверены. Docker-конфигурация проверена; сборка и запуск контейнеров остаются непроверенными до восстановления Docker Desktop.
