AutoRent — защита лабораторных работ 3–7

Сценарий демонстрации
1. Запустить seed.py, API и Streamlit либо docker compose up --build.
2. Открыть Swagger /docs. Выполнить GET /cars; показать JSON и код 200.
3. Создать категорию через POST /categories: name=Демо, daily_rate=18000.
   Показать код 201. Повтор того же имени даст 409; отрицательный тариф — 422.
4. PATCH категории: изменить только тариф. Название должно сохраниться.
5. В интерфейсе открыть автомобили, найти Toyota и задать диапазон тарифов.
6. Через форму добавить клиента и автомобиль, затем аренду. Повторная аренда
   той же машины с пересекающимися датами должна вернуть 409.
7. Попробовать удалить используемую категорию: 409. Удалить созданную аренду,
   затем автомобиль и категорию. GET удалённого ID возвращает 404.
8. Выполнить python -m pytest -q и python verify.py.
9. Показать Dockerfile, адрес backend во frontend и том rental_data.
   После обычного down/up данные сохраняются. Сборку показать при работающем Docker.

Лабораторная 3
REST API предоставляет ресурсы через HTTP. GET читает данные, POST создаёт.
FastAPI принимает JSON; Pydantic проверяет типы и ограничения до работы с БД.
Depends(get_session) создаёт сессию на запрос и закрывает её после обработки.
Swagger /docs строится по OpenAPI и позволяет интерактивно проверить маршруты.
200 означает успешное чтение, 201 — создание, 404 — отсутствие, 422 — неверный ввод.

Лабораторная 4
CRUD: Create POST, Read GET, Update PUT/PATCH, Delete DELETE.
PUT обычно заменяет весь ресурс, PATCH обновляет отдельные поля и сокращает тело запроса.
Query-параметры передаются после ?: /cars?search=Toyota&min_price=10000.
exclude_unset=True оставляет только явно переданные поля. Сам по себе он не запрещает
null: после объединения с записью валидируется полная create-схема, запрещающая null.
Поиск объекта перед удалением позволяет вернуть понятный 404 и проверить связи.
SQLModel формирует параметризованные SQL-запросы; ввод пользователя не вставляется в SQL.

Лабораторная 5
Streamlit отправляет HTTP-запросы к FastAPI через requests и получает JSON.
params передаёт параметры URL, json — тело запроса. UI не открывает базу напрямую.
При отказе сервера requests выбрасывает исключение; UI показывает понятную ошибку.
Timeout 10 секунд ограничивает ожидание. После успешного изменения rerun обновляет таблицу.
Streamlit выполняет скрипт заново при действии пользователя; формы объединяют ввод.
Преимущества: быстрый интерфейс на Python. Ограничения: меньше контроля над дизайном
и поведением, чем при отдельном HTML/CSS/JavaScript приложении.

Лабораторная 6
Контейнер изолирует процессы, разделяя ядро хоста; виртуальная машина имеет собственную ОС.
WORKDIR выбирает рабочую папку, COPY копирует файлы, RUN выполняется при сборке,
CMD задаёт команду запуска, EXPOSE документирует порт, но не публикует его.
.dockerignore исключает окружение, секреты, базы и кеши из контекста сборки.
Встроенный DNS Docker разрешает имя backend внутри сети Compose. localhost во frontend
означал бы сам frontend-контейнер, поэтому используется http://backend:8000.
Файл в writable layer теряется при удалении контейнера; named volume хранит SQLite отдельно.

Лабораторная 7
Автотесты воспроизводимо проверяют поведение после изменений и предотвращают регрессии.
TestClient вызывает ASGI-приложение без отдельного процесса uvicorn; HTTPX обеспечивает
HTTP-клиент. Подмена get_session направляет запросы в временную тестовую базу.
ИИ ускоряет генерацию сценариев и ревью, но не доказывает правильность: нужны реальные тесты.
Проверены опасные случаи: null в PATCH, дубликаты, отсутствующие внешние ключи,
удаление используемых записей, отрицательные тарифы, неверные даты и пересечения аренды.
Публикация в интернете потребует авторизации и отдельной настройки защиты.
